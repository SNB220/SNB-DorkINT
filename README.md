# SNB-DorkINT

Master the art of advanced Google searching with pre-built queries and templates

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## Features

- **Multiple Search Engines Support**: Google, Bing, DuckDuckGo, Brave, Yahoo, and Yandex
- **Pre-built Dork Templates**: Popular search patterns ready to use
- **Custom Dork Manager**: Save, export, and import your own dork operators
- **Search History & Favorites**: Track and save your frequent searches
- **Dark Mode**: Retro-styled dark theme with neon aesthetics
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile

## Quick Start

### Live Demo
👉 **[Try SNB-DorkINT Live](https://snb220.github.io/SNB-DorkINT/)** 

### Local Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/SNB220/SNB-DorkINT.git
   ```

2. **Open the tool**
   - Simply open `SNB-DorkINT.html` in your web browser
   - No installation or dependencies required!

## 📖 How to Use

1. **Select a Search Engine** - Choose from Google, Bing, DuckDuckGo, Brave, Yahoo, or Yandex
2. **Pick a Dork Type** - Select from various categories:
   - Basic Search (site:, inurl:, intitle:, etc.)
   - File & Directory searches
   - Login & Admin Pages
   - Sensitive Data queries
   - And more!
3. **Enter Keywords** - Add your search terms
4. **Search** - Click the search button or use templates
5. **Save Favorites** - Save frequently used queries for quick access

## Features Overview

### Template Categories
- **Admin Panel Finder** - Find admin panels on websites
- **Document Searcher** - Locate PDF and other documents
- **File Directory Lister** - Find exposed file directories
- **Login Page Finder** - Discover login pages
- **Technology Detector** - Identify technologies used on sites
- **Config File Finder** - Locate configuration files
- **Email Harvester** - Find email addresses on domains
- **SQL Injection Finder** - Find pages with query parameters

### Custom Dorks
- Create and save your own dork operators
- Export/Import custom dorks as JSON
- Share dork collections with others

### Additional Features
- **Dark Mode** - Retro terminal-inspired design
- **Favorites System** - Save your most-used queries
- **Search History** - Track your recent searches
- **Copy to Clipboard** - Quick copy functionality
- **Quick Refresh** - Clear form with one click
